From one tool to many

RAG gave the model one tool: retrieval. An agent can use several, and decide for itself when to call them.

Autonomous

Runs multiple steps without a new prompt from you at each one.

Goal-directed

Works toward the outcome you gave it and checks its own progress.

Tool-using

Calls a search, a database, an app, on its own initiative, not just yours.

All three together are what separate an agent from a chatbot that only answers what you type.

Not hypothetical

If you've used Claude or ChatGPT recently, you've probably already delegated a multi-step task to one.

Ask for the outcome, not the steps

Claude's Cowork mode plans a multi-step task across files and apps, then carries it out end to end.

Builds while you wait

ChatGPT's agent mode can research, draft a document or spreadsheet, and pause only when it needs your input.

Lives inside tools you already use

On GitHub it can open a pull request for review. In Slack, a teammate can delegate a task right from the channel.

You approve the goal, and the final result. Everything in between, it plans and does itself.

Same task, delegated

Remember screening abstracts, back in Part 2? Now imagine it as a loop, not a single prompt.

Search ClinicalTrials.gov → Check each result against your criteria → Flag the one that doesn't clearly fit → Ask you only about that one → Compile the results

It still needs the same reproducible decision rule from Exercise 1: criteria, format, a reason for every call. An agent just runs that rule across more steps, unsupervised, so a vague rule now compounds across the whole loop instead of one answer.

How mature is this, really?

Earlier than the hype suggests. A 2026 scoping review found seven published healthcare studies. None yet in public health.

CDC's own guidance describes agentic “Deep Research” tools doing autonomous multi-step literature synthesis and cross-jurisdiction policy scans, close to work you already do. It also says: never point one at PHI, PII, or paywalled sources, and always have an expert validate the output before it informs a decision or goes public.

Same lesson as the rest of this course: the model can move fast. Whether that's trustworthy is a design choice, not a given. Next, a system built around exactly that trade-off.

Centers for Disease Control and Prevention, “Considerations for Agentic Research in Public Health,” 2026; and a scoping review of agentic AI in healthcare, npj Digital Medicine, 2026.
